# 🛡️ Custom SIEM using ELK Stack

This project is a custom-built Security Information and Event Management (SIEM) system using the ELK Stack (Elasticsearch, Logstash, and Kibana). It includes log ingestion, brute-force detection, visualization dashboards, and alerting.

## 📌 Features
- Real-time log analysis
- Brute-force attack detection
- Kibana dashboard for visual monitoring
- Sample alert rules and simulation scripts

## 🔧 Tech Stack
- Elasticsearch
- Logstash
- Kibana
- Filebeat
- Python (for simulation scripts)
